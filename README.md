# InsightFlow AI MVP

A browser-based SaaS prototype for an AI marketing intelligence platform for SMEs.

## What is included
- React + Vite web app
- KPI dashboard
- Campaign performance table
- ROAS, CAC, conversion calculations
- AI-style campaign recommendations
- Charts and filtering
- Responsive design

## How to run
1. Install Node.js
2. Open this folder in a terminal
3. Run:

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.
